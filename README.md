# Breathe

A guided morning breathing practice: a 3-day starter, a 4-week programme, then maintenance. Single-file web app, installable as a PWA, works offline.

## Use it on your phone

1. Open the GitHub Pages address for this repo in Chrome: `https://wangden-bhutia.github.io/breathe/`
   (Pages must be turned on: repo **Settings → Pages → Deploy from branch → main / root**.)
2. Tap **Install** on the home screen card, or Chrome menu → **Add to Home screen**.
3. Open it once while online; after that it works offline.

Opening `index.html` straight from a file also runs, but the screen may sleep mid-session (wake lock needs HTTPS) and it won't work offline.

## Reminders

Reminder times show as banners inside the app. A web app can't reliably alert you while it's closed, so set a phone alarm for the same times.

## Data

Everything is stored on the device. Use **Settings → Export data** for a JSON backup, and **Import data** to restore it.
